# miner-game

Простая игра/симуляция написанная на Go. Идея: управлять шахтёрами (miners), собирать ресурсы, прокачивать оборудование и соревноваться за наибольшее количество добытого материала.

## Возможности

- Логика добычи ресурсов
- Управление шахтёрами (создание, апгрейд)
- Сохранение/загрузка прогресса
- CLI-интерфейс (или простая серверная версия) на Go

## Технологии

- Go (версия >= 1.20)

## Быстрый старт

1. Клонируйте репозиторий:

   git clone https://github.com/recxvery/miner-game.git
   cd miner-game

2. Установите зависимости и соберите проект:

   go mod download
   go build -o miner-game ./...

3. Запуск:

   ./miner-game

Или в режиме разработки:

   go run ./cmd/main.go
